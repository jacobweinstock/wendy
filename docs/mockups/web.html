wendy: web UI wireframes

Superseded by mockup/, which the web UI now follows. These are the earlier screens and words, kept for reference.

Low-fidelity wireframes. The web UI has the same screens, wording, statuses and actions as the TUI (tui.md), so learning one means you know the other. It is built with templ + htmx; live parts (progress, logs, status) update over SSE.

Statuses: ✓ passed ✗ failed ! errored ● running ○ waiting ‖ paused – not run. failed means Tinkerbell or CAPT misbehaved; errored means wendy or the host broke.

Global keys work in the web UI too: / filter, ⌘K or : command palette, n new run, ? help.
